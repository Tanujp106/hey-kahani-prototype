# Public samples only

`preview-sample.mp3` is a **design-preview stand-in** (trimmed internet sample) so the
Koel overlay wavelength can be developed. It is not approved story audio and must
be replaced with a public excerpt before launch.

Once approved, add the public excerpt and set each product’s `metadata.previewSrc`
(or the audio element’s `src`); the shared controller enables playback automatically.
Future Shopify rendering supplies the approved Files/CDN URL in the same markup.

Do not add protected full-length audio.
