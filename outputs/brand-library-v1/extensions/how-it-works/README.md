# How it works illustrations

Three original editable SVG scenes for the homepage's numbered Choose → Place →
Listen sequence, requested November 16, 2026. These are SVG-only additions to the
selected loose-cut illustration system, separate from the original 36 assets.

- `choose-a-koel.svg`: a hand choosing one of three circular Koels, each with
  new abstract nature artwork.
- `place-on-player.svg`: a hand bringing the chosen disc to the top plate.
- `story-begins.svg`: the same disc on the Player with open listening ripples.

The Player is a simplified editorial drawing informed by the supplied studio
reference at `shopify-homepage/assets/images/product/hk-shot-07.png`: cream
cylinder, arch handle, five controls, Gulab speaker band and wood-toned base.
It is not an approved merchandise render. The disc designs do not identify
published stories or products. There are no new claims about setup or features.

Use all artwork proportionally. Keep hands, discs, controls and sound arcs
inside the visible media area. Individual artwork has a transparent background;
the website supplies Kesar and light Sky/Mango grounds. There are no raster
embeds, gradients, filters, text labels or external resources in the vectors.

The website embeds matching copies in
`shopify-homepage/assets/images/brand-library/illustrations/`. When updating a
source drawing, update its website copy too. `manifest.json` documents each role.

All three scenes were parsed as SVG/XML and rendered with Sharp/libvips for
asset inspection. These asset checks do not verify the page's browser layout.
